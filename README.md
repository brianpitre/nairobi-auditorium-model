# Nairobi Auditorium Model

Interactive 3D massing model of a 20 × 55 × 7 m auditorium (Draft 2, 29 Sep 2026): a 15 × 7 × 0.8 m stage and 1,360 metal folding chairs on 1 m rows, either side of a 2 m centre aisle. Plan, long section and eye-level views, fully dimensioned.

**Live:** https://brianpitre.github.io/nairobi-auditorium-model/

`index.html` is generated. Edit `auditorium_model.html` in the project folder, run `python3 build_site.py`, then commit and push here. Pages rebuilds in about a minute.
